# The Quiet Manor

A cozy, single-file web app for winding down at the end of the day. Step into a softly animated manor and choose from three gentle activities — no accounts, no ads, no dependencies. Just open the HTML file in a browser.

## ✨ Features

**🕯️ The Letter Desk** — A quiet journaling space. Pick a theme (Reflection, Gratitude, Release, or Comfort), get a rotating prompt, write freely in the textarea, and "seal" your letter with a small closing animation when you're done. Nothing is saved — it's meant to be let go of, not archived.

**🌬️ The Breathing Room** — A guided breathing exercise with an animated glowing orb that expands and contracts in sync with the pattern. Choose between:
- **4-4-4** — inhale, hold, exhale, 4 seconds each
- **4-7-8** — a longer, more relaxing pattern popular for sleep

**🏚️ The Night Watch** — A gentle point-and-click walkthrough of five rooms in the manor. Each has a small creature or detail that needs quiet tending — switch off a nightlight, blow out a candle, water a flower, lift a kettle, tuck in a blanket. Visit all five to reach the closing "All is Well" scene.

## 🚀 Getting Started

No build tools, no npm install, no server required.

1. Clone or download this repository
2. Open `quiet-manor.html` directly in any modern web browser

That's it. Everything — HTML, CSS, and JavaScript — lives in a single self-contained file.

## 🛠️ Built With

- Plain HTML, CSS, and JavaScript (no frameworks or libraries)
- Inline hand-drawn SVG illustrations
- CSS keyframe animations for fire flicker, twinkling stars, and character movement

## 📁 Project Structure

```
quiet-manor.html   # everything: markup, styles, and logic in one file
```

## 💡 Notes

- All state (journal text, breathing progress, which rooms you've tended) lives only in memory for the current session — refreshing the page resets everything.
- Designed to be relaxing rather than "gamified" — there's no scoring, timer pressure, or win condition beyond a peaceful closing scene.
